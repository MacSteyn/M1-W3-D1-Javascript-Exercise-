# JavaScript Console Practice Exercises

This repository contains exercises completed using the **JavaScript Console** in Google Chrome. The purpose of these exercises is to practice writing, testing, and debugging JavaScript code directly in the browser without creating separate HTML files.  

## Key Highlights

- **Browser Console Usage**:  
  - Open Chrome → View → Developer → JavaScript Console  
  - Shortcuts: `Ctrl + Shift + J` (Windows), `Cmd + Option + J` (Mac)  
  - Allows quick testing, code monitoring, and debugging.

- **Exercises Included**:  
  1. **Functions**  
     - Created functions, called them, and passed arguments.  
     - Practiced concatenating strings with variables.  
  2. **Conditional Statements**  
     - `if-else` and `if-elseif-else` statements.  
     - Logical operators: `&&` (AND), `||` (OR).  
  3. **Switch Statement**  
     - Tested multiple conditions using the `switch` structure.  

- **Learning Outcomes**:  
  - Understand how to define and execute functions in JavaScript.  
  - Learn decision-making using conditional statements.  
  - Use console for real-time debugging and testing.  

- **Screenshots**:  
  - Each exercise includes screenshots of the console output to verify code execution.
